# WhatToEat

A personal PWA for tracking ingredients at home and planning today/tomorrow meals.

## Features

- Ingredient shelf grouped by staple, produce, protein, and other
- Add and edit ingredients with OpenMoji icons
- Expiry date picker
- Mark ingredients as used up
- Today/tomorrow meal planning with automatic daily rollover
- Local browser storage, no account or backend required
- Basic PWA manifest and service worker

## Deploy With GitHub Pages

1. Create a GitHub repository.
2. Push this folder to the repository's `main` branch.
3. In GitHub, open `Settings` -> `Pages`.
4. Set source to `Deploy from a branch`.
5. Select `main` and `/root`.
6. Open the Pages URL on iPhone Safari and choose `Add to Home Screen`.

The app stores data locally on each device through browser storage.
